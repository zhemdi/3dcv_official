# 3D компьютерное зрение и графика

Материалы курса (МГУ, факультет ИИ).

| папка | что внутри |
|---|---|
| `lectures/` | презентации лекций, по папке на лекцию |
| `seminars/` | материалы семинаров, по папке на семинар |
| `other_materials/` | всё остальное: презентации о проектах, ссылки, дополнительные материалы |

Нумерация папок совпадает с номером лекции: `1_Introduction`, `2_...` и так далее.
